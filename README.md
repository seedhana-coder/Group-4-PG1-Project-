# CareBridge Hospital

## About the Project

CareBridge Hospital is a modern web-based hospital application.

The project is developed as part of the Programming 1 project.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Git
- GitHub

## Features

- Hospital home page
- Patient registration
- Patient name validation
- Patient age validation
- Patient ID validation
- Registration confirmation
